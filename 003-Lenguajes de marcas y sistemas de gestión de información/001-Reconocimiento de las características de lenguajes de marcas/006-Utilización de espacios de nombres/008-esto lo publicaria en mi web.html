JOCARSA - Namespace Persona

Este URI identifica el espacio de nombres XML utilizado para representar personas en documentos XML de JOCARSA.

URI del espacio de nombres

https://jocarsa.com/persona

Elementos

  • persona - Representa una persona.
  • nombre - Nombre de la persona.
  • apellidos - Apellidos de la persona.
  • email - Dirección de correo electrónico.

Ejemplo

<?xml version="1.0" encoding="UTF-8"?>

<jocarsa:persona
    xmlns:jocarsa="https://jocarsa.com/persona">

    <jocarsa:nombre>Jose Vicente</jocarsa:nombre>
    <jocarsa:apellidos>Carratalá Sanchis</jocarsa:apellidos>
    <jocarsa:email>info@josevicentecarratala.com</jocarsa:email>

</jocarsa:persona>
