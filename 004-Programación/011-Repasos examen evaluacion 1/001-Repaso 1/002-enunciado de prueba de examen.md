Tienes que hacer una tienda online
En esa tienda online hay productos

-Crea una tabla de productos en MySQL que tenga: id, nombre, descripcion, precio
-Crea un controlador Python para servir una web de productos (front) y el mismo controlador debe servir un formulario de nuevo producto (3 endpoints/routes): lista, formulario, inserta)
-Crea una web front con la tienda online, y crea una web admin (vuelta) con el formulario de insertar nuevo producto (ida)
