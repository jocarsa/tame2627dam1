Para el resto del curso, es decir, para todas las aplicaciones que tenéis que entregar en el resto del curso:

Una aplicación completa cumple las siguientes condiciones

1.-Tiene usuarios que entran a la aplicación por la parte de delante (frontoffice)
2.-Los usuarios generalmente se pueden hacer una cuenta (signup)
3.-Los usuarios podrán entrar en futuros dias con su cuenta (sign-in / login)
4.-Los usuarios podrán tener su espacio privado - podrán tener elementos compartidos

5.-Debe haber un panel de administración donde los administradores pueden gestionar (backoffice)
	-Pueden ver (select)
  -Pueden crear nuevos registros manualmente (insert)
  -Pueden eliminar elementos si incumplen normas (delete)
  -Pueden actualizar información (update)
