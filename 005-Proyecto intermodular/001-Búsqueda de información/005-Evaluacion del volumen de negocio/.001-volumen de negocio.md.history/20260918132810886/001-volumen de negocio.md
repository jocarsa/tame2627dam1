Sí. Si reducimos la pregunta a **desarrollo de software** y pensamos en los próximos 5–10 años, hay un contraste bastante claro:

| Tendencia                | Subsector                                                        | Previsión |
| ------------------------ | ---------------------------------------------------------------- | --------: |
| 🟢 Crecimiento fuerte    | **Aplicaciones empresariales con IA / agentes / automatización** |       ↑↑↑ |
| 🔴 Presión/decrecimiento | **Desarrollo tradicional de aplicaciones a medida simples**      |         ↓ |

### 🟢 Crecimiento: aplicaciones empresariales con IA

No me refiero tanto a crear modelos fundacionales, sino a **crear aplicaciones que incorporan IA para resolver procesos empresariales concretos**: agentes, automatización documental, RAG, asistentes especializados, análisis de datos, integración con ERP/CRM, generación de contenidos, etc.

Los números actuales son muy fuertes. Gartner estima que el gasto mundial en **AI Software** pasa de unos **288.000 M$ en 2025 a 462.000 M$ en 2026 y 656.000 M$ en 2027**. Las plataformas específicamente destinadas al desarrollo de aplicaciones de IA crecerían alrededor de un **39% solamente en 2026**. ([Gartner][1])

Todavía más llamativo es el software de **IA agéntica**: Gartner proyecta aproximadamente **985.000 M$ de gasto en 2030**, con un CAGR 2025–2030 del **62,7%**. ([Gartner][2])

Por tanto, dentro de desarrollo:

**software vertical + IA + automatización + integración con los datos del cliente**

me parece una categoría especialmente importante.

Ejemplos serían:

> aplicación para gestionar prácticas de FP + IA para asignar alumnos a empresas
> plataforma educativa + generación/evaluación automática
> ERP especializado + agentes que ejecutan tareas
> aplicación documental + RAG sobre documentación privada
> CRM vertical + automatización inteligente

Y esto es interesante porque el mercado general de aplicaciones empresariales también sigue creciendo: Gartner espera crecimiento de doble dígito hasta 2030. ([Gartner][3])

### 🔴 Bajo presión: desarrollo tradicional de aplicaciones sencillas a medida

Aquí haría una precisión importante: **no encuentro una previsión sólida que diga que "el desarrollo de software a medida" en conjunto vaya a disminuir en facturación**. De hecho, muchas categorías de servicios de software siguen creciendo.

Lo que sí parece estructuralmente amenazado es el **valor económico de producir aplicaciones relativamente convencionales mediante programación manual**:

> CRUD + base de datos + formularios + login + informes + API + panel administrativo.

¿Por qué?

Porque cada vez compite más contra:

**low-code/no-code + SaaS configurable + componentes reutilizables + generación de código mediante IA.**

El mercado low-code, por ejemplo, alcanzaría unos **58.200 M$ en 2029**, creciendo aproximadamente un **14,1% anual**. ([Gartner][4]) Gartner ya describe una transición de equipos de ingeniería desde stacks tradicionales hacia plataformas low-code para desarrollar y mantener aplicaciones empresariales. ([Gartner][5])

Esto produce una paradoja importante:

**no necesariamente se harán menos aplicaciones; puede ocurrir exactamente lo contrario. Lo que puede caer drásticamente es el coste de producir cada aplicación sencilla.**

Y eso reduce el volumen de negocio disponible para una empresa cuyo producto sea simplemente "te programo una aplicación CRUD desde cero".

### Y aquí veo algo especialmente relevante para tu caso

Hay una tercera categoría que yo separaría:

**software vertical especializado.**

Por ejemplo:

```text
                    CRECIMIENTO
                        ↑
                        │
         IA / agentes  │  Software vertical + IA
                        │       ★
                        │
────────────────────────┼────────────────────────→ especialización
                        │
 CRUD genérico          │  Software vertical
 desarrollo manual      │  tradicional
                        │
                        ↓
                   DECRECIMIENTO
```

Tu ventaja potencial no estaría tanto en competir haciendo **"desarrollo de aplicaciones"** genérico.

Estaría en algo mucho más concreto:

**"software vertical para educación y formación construido muy rápidamente y enriquecido con IA".**

Ahí coinciden tres tendencias favorables: crecimiento del software empresarial, crecimiento extraordinario de IA aplicada y reducción radical del coste de desarrollo gracias a IA/low-code.

De hecho, hay una consecuencia estratégica bastante interesante: **la IA puede perjudicar al programador que vende horas de programación y beneficiar muchísimo al pequeño fabricante de software que vende soluciones completas.** Para una estructura pequeña, esa diferencia puede ser enorme.
