KPI de muestra

1.-Que el software funcione bien
2.-Que la interfaz sea agradable/intuitiva
3.-Que la información se muestre como se debe (es decir, que el público entienda la aplicación)

Depurar (miramos si da algun error en la consola o en terminal)-
probar - probamos todas las funciones, todos los botones, antes de lanzarlo

Usando usuarios de prueba
Se les presenta la aplicación
Se les pide que hagan una operación (compra un producto)
Y se mide si ejecutan la tarea exitosamente

Realizando pruebas con usuario
entrevistas:
como harías esta aplicación?
que otras aplicaciones usas?
que cambiarías?
Que te gusta y que no te gusta?
