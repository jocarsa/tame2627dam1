# Bases de datos centralizadas y bases de datos distribuidas. Técnicas de fragmentación
- centralizadas
	- Toda la información se encuentra en la misma máquina
- Descentralizadas o distribuidas 
	- La base de datos se distribuye en varias máquinas formando un cluster
- Fragmentación
	- Replicación, CDN - velocidad, concurrencia
	- Fragmentación real - tamaño
